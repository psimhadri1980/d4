# Keyboard shortcuts and URLs

## Shortcuts

| Keys | Action |
|---|---|
| `Ctrl K` / `⌘ K` | Open search (pages, elements, queries) |
| Arrow keys, `Enter` | Move in and open a search result |
| `Esc` | Close search |
| Double-click a graph node | Expand its neighbours |

## Useful URLs

All are under `/w/<workspace-id>/`:

| Path | Page |
|---|---|
| *(empty)* | Explorer |
| `e/<id>` | An element; `e/<id>/edit` to edit it |
| `new` or `new?type=Decision` | New element |
| `queries?section=catalog\|studio\|stewardship` | Queries; open tabs in `?tabs=run:ID,edit:ID&active=…` |
| `matrices?kind=capability-application\|data-store-roles\|lifecycle` | Matrices |
| `compare` | Compare (both sides in the URL) |
| `roadmap` | Roadmap (scope, lanes, zoom in the URL) |
| `proposals?show=open\|review\|closed\|all` | Proposals |
| `import`, `jobs`, `reports` | Data and reporting |
| `connectors`, `backups`, `admin/workspaces`, `admin/people`, `admin/webhooks`, `admin/usage` | Admin |

Older `/catalog`, `/studio` and `/stewardship` links still work and open the matching query tab.
