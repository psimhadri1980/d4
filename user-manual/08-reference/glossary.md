# Glossary

| Term | Meaning |
|---|---|
| **As of** | A date that filters the model to what is valid on that day |
| **Baseline** | The real model, without any scenario |
| **Catalog** | The set of published queries you may run |
| **Certified** | A steward's mark that a query is trustworthy |
| **Connector** | A configured link that syncs an external system into a workspace |
| **Critical path** | The chain of deliverables whose delays delay the end date |
| **Element** | One thing in the model (a node in the graph) |
| **Event log** | Append-only record of every change; basis of History and restore |
| **External key** | An element's identifier in a source system |
| **Layer** | Group of element types (Strategy … Planning) shown in one colour |
| **Lifecycle** | The state of an element from IDEA to RETIRED |
| **Metamodel** | The rules of a workspace: types, attributes, relationships, rules |
| **Neighbourhood** | An element and what is connected to it within a depth |
| **Pack** | An industry extension of the starter metamodel (Banking, Insurance) |
| **Proposal** | A reviewed batch of changes applied together |
| **Query author / steward** | Roles that write / approve catalog queries |
| **Relationship** | A directed, typed link between two elements |
| **Scenario** | A what-if layer over the baseline |
| **Soft delete** | Hiding an element while keeping its history |
| **Tenant** | Your organisation's separate area of D4, with its own database |
| **TIME class** | Tolerate, Invest, Migrate, Eliminate: a disposition for applications |
| **Version** | Counter of an element's changes; protects against overwriting |
| **Workspace** | One model within a tenant |
